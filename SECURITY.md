# Security Policy

DJI Link communicates with aircraft and remote-controller hardware. Please do not publish credentials, private network details, serial numbers, or unredacted logs in public issues.

For a security-sensitive issue in the application, updater, release pipeline, or Pi services, contact the maintainers privately through the email listed in the profile or in Telegram listed in the profile instead of opening a public issue. Include a clear description, affected commit or release, reproduction steps, and a minimal proof of impact.

This project is unofficial and is not affiliated with DJI. Do not use a security report to request bypasses of account binding, safety systems, or legal restrictions.
